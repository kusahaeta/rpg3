# にゃんこファンタジー　〜一匹では弱くても〜

2頭身のにゃんこたちが旅をする、ブラウザで遊べる3DコマンドRPG。
企画書は `spec/nyanko_fantasy_plot.md`。探索フィールド・ターン制バトル・会話シーンの仕組みは、前作（`../rpg`「銀河鉄路 ノクターン」）のものを流用しています。

## 起動

ビルド不要。`index.html` をブラウザで開くだけで遊べます（WebGL 対応ブラウザ推奨）。ローカルサーバーを使う場合：

```bash
node .claude/serve.js
```

→ http://localhost:8912

セーブデータはブラウザの localStorage（`nyanko_fantasy_v1`）に保存されます。探索のメニュー（Esc）の「データを初期化」でリセットできます。

### Android アプリ

`android/` は、このフォルダの Web 版をそのまま WebView で包んだアプリ（サーバー不要・ネットワーク権限なし）。ビルドのたびに `index.html`・`css/`・`js/`・`vendor/` を APK の中へ写すので、ゲーム側の変更はビルドし直すだけで入ります。

```bash
cd android && JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home" ./gradlew assembleDebug
```

→ `android/app/build/outputs/apk/debug/app-debug.apk`（`adb install -r` で入れる）。横画面固定・全画面・画面スリープなし。裏に回すと BGM を止め、戻るキーではゲームを終わらせず裏に回すだけ。セーブはアプリ内の localStorage に残ります。デバッグ版は Chrome の `chrome://inspect` から中身を調べられます。

## デバッグ：章・段階へジャンプ

URL に `?debug` を付けて開く（例：`http://localhost:8912/?debug`）と、探索のメニューに「デバッグ：章へジャンプ」が出ます。`?debug=0` で無効に戻ります。

- 各章の段階（会話・探索・戦闘）を選ぶと、その段階の直前まで進めた状態になる（飛ばした会話で加わる仲間も加入）
- 「編成のレベルを推奨レベルまで上げる」で、その段階の戦闘の推奨レベルまで上げる
- 最初のジャンプの前にセーブを退避し、「ジャンプ前のセーブに戻す」で元に戻せる

### スマホ・タブレット（横画面）

タッチで操作すると、スマホ用の表示に切り替わります（キーボードを押すと PC 用の表示に戻る）。縦画面のときは「横にしてね」が出ます。対応しているブラウザでは、最初のタップで全画面・横向き固定になります（iPhone の Safari では、共有メニューの「ホーム画面に追加」から開くと全画面で遊べます）。

| 操作 | 動作 |
| --- | --- |
| 画面の左半分をなぞる | 移動（スティックを端まで倒すとダッシュ） |
| 画面の右半分をドラッグ／2本指でつまむ | 視点の回転／ズーム |
| 右半分をタップ・「攻撃」 | 攻撃（先制攻撃） |
| 「ジャンプ」「調べる」 | それぞれの操作（調べられるものが近いと「調べる」が光る） |
| 下の顔アイコン | 先頭の子を交代 |

戦闘・会話・メニューは、ボタンや敵をタップして遊べます（必殺技は顔のアイコンをタップ、対象を選ぶ画面には「キャンセル」ボタン）。

スマホでは最初から「省エネ」の画質になります（30fps・画面の細かさを抑える・ふちのギザギザ取りなし・影を小さく・3D表示中は背景の光の粒を止める）。探索のメニューの「画質」で、なめらか（60fps）と切り替えられます。

## システム

- **ターン制バトル**：速度による行動順、共有のスキルポイント、EP をためて撃つ必殺技、弱点属性で靭性を削る「弱点撃破」（属性はキャラではなく技ごと。技のボタンと説明に属性のしるしが出る）、ボスのフェーズ移行（弱点が変わる）と増援
- **にゃんこらしさ**：タマはときどき戦闘中に寝てしまう。シロの魔法はたまに失敗して魚が降ってくる
- **どうぐ**：はじめから戦闘中に使える（ターンを使う・SPは増減しない）。にぼしおにぎり（単体回復）・かつおぶし（全体回復）・またたびの実（必殺技エネルギー）・ねこ缶（戦闘不能から起こす）。道具屋で買え、ひとつにつき9こまで持てる。だいじなものの猫じゃらし（第六章でチョキチョキにもらう）は、魔王の前で振ると1ターン夢中にさせる。定義は `js/data.js` の `ITEMS`
- **友情**：いっしょに戦う・会話を進めると、二匹ずつの友情が深まる（Lv2 戦闘中の掛け合い／Lv3 コンボスキル／Lv4 特別イベント／Lv5 最終スキル）。戦闘では友情ゲージがたまり、コンボスキルを撃てる
- **コンボスキル**：ニャンコブレイク（ミケ＋クロ）、ファイアボール（ミケ＋シロ）、黒白連撃（クロ＋シロ）、にゃんヒール（タマ＋だれか）、号令（マオウ＋だれか）。最終決戦では「にゃんこオールスターズ」
- **探索**：区画ごとの敵・宝箱・爪とぎの丸太（爪を研ぐと先頭の子の初手技が準備され、次の戦闘開始時に発動）・住人との会話・お店（魚屋・武器屋・道具屋・宿屋）。区画はゲートでつながり、物語を進めると先へ行ける。HPは宿屋で休むと回復。ワールドマップ（M）からいつでも訪れた場所へワープ
- **育成**：戦闘に勝つと編成の仲間がけいけんちを得て、その場でレベルアップ
- **武器**：にゃんこごとに武器は1種類（ミケ＝剣、クロ＝刀、シロ＝杖、タマ＝まくら、マオウ＝笏）。同じ種類の武器が何本もあり、武器を替えると通常攻撃・戦闘スキル・必殺技がまるごと変わる（とくせい・初手技はその子のまま）。はじめの武器は物語とともに技が育つ。新しい武器は武器屋で買うか、青く光る宝箱から見つかる。「なかま」の画面で装備し、武器屋で +1〜+5 に鍛えるとHP・攻撃力・防御力が上がる（+5 で武器の先が光る）。定義は `js/weapons.js`
- **敵の強さ**：仲間が少ないうちは、敵の体力と攻撃を控えめにする（`js/battle.js` の `foeScale` と `FOE_HP`）

## 3Dグラフィック

Three.js（`vendor/three-bundle.js` に同梱）によるリアルタイム3D描画。キャラクター・敵・背景はすべてコードで生成しています。

- **2頭身のにゃんこ**（`js/gfx/cats.js`）：大きな頭と小さな体、耳・しっぽ・肉球。毛並みの柄（三毛・単色・ポイント）、表情ごとに描き分けた顔（Canvas テクスチャ）、ハチマキ・マント・帽子・スカーフ・王冠などの衣装と武器。前作のポーズ・表情の仕組みにそのまま乗るので、戦闘・探索・会話の演技は共通
- **敵**（`js/gfx/monsters.js`）：スライム・きのこ・リス・ネズミ・カラス・岩・のら犬・イノシシ・ゴースト・ピエロ・影猫・魔族・魔王・コドク など
- **会話シーン**（`js/stage.js`）：物語の場所で、にゃんこたちが向き合って話し手を見る。表情と身振り、まばたきと口パク。カメラは全景・寄り・肩越しを切り替え、手前のにゃんこが話し手をふさがないよう角度を選ぶ
- **技のモーション**（`js/gfx/moves.js`）：技ごとに `anim` で動きを選ぶ（まくらを振りまわす・しっぽでなぎ払う・ためて斬る・影分身・空から雷・氷柱・歌・なでなで・かばう構え など）。`anim` のない技は、近接なら飛びこんで斬り、遠距離なら弾を撃つ。友情技は、ふたり（みんな）で動く（左右から十字に斬る・投げた魚に火をつける・声を合わせて歌う・号令で奮い立つ など）。敵の技も `js/gfx/foe-moves.js` で技ごとに動く（スライムはのしかかり、リスはどんぐりを投げ、燭台は炎を吐く など）。ボスがためて撃つ大技は、ボスへ寄ってためを見せてから、ボスごとの専用の動きで撃つ（大なべをひっくりかえす・寝返りで転がる・猫の形に刈りこむ・地割れ・大きな肉球 など）。コドクの技は中身が見た目でわかる（孤独は黒い丸で包んで閉ざす、思い出消去は思い出が色を失って砕ける、疑心は友情の糸が切れる、絶望は黒い影が地面に広がる）
- **ステージ**（`js/gfx/env.js` の `THEMES`）：草原・夜・森・街道・王国・塔・谷・洞窟・遺跡・魔王領・樹・根・世界の果て・夢
- **ポストエフェクト**：ブルーム、ACESトーンマッピング、ビネット、SMAA

`dev/catlab.html` は、にゃんこと敵のモデルを並べて確認する開発用ページです（`?k=mike,kuro` でにゃんこ、`?e=slime,kinoko` で敵、`&pose=` `&expr=` でポーズと表情）。

## 台本の書き方

台本は `js/scenario.js` / `js/scenario2.js` の `SCENES`。1行が `[話し手, せりふ, { 演出 }]` です。

- 話し手：`n`（ナレーション）、にゃんこ（`mike` `kuro` `shiro` `tama` `maou`）、住人（`js/npcs.js` のキー）、敵（`e:` ＋ 敵のキー）
- 演出：`f` 表情、`g` 身振り、`to` 話しかける相手、`cam` カメラ（`wide` / `look:地点` / 人物のキー / `keep` 前の行のまま など）、`later: [秒, 演出]` 少しあとに演出（`cam` も切りかえられる）、`move` 歩かせる（`speed` で速さ）、`waitMove` 前の行で歩きはじめた人物が着いてから、この行を出す、`lock: 秒` この行の演出を見せるあいだ、クリックやキーで先へ進めない（流れ星が落ちるところなど）、`enter` 登場、`r` 周りの反応、`look` 視線、`fx` 演出（流れ星など。`seal` 封印の扉が開く、`timeshift` 時の水晶で今と昔を切りかえる など）
- 選択肢：`{ c: [[選択肢の文, [返事の行...], { 演出 }], ...] }`
- 仲間になる：`{ give: 'shiro' }`、友情：`{ bond: ['mike', 'kuro', 5] }`、物語のフラグ：`{ flag: 'kuroGuard' }`
- 舞台：シーンの `stage`（区画 `zone`、立ち位置 `at`、向き `face`、配役 `cast`、全景カメラ `wide`、地点 `points`）。配役を書かない人物は、仲間は隊列に、ほかの人物は向かいに自動で並ぶ

物語の段階（会話 → 目的地 → 戦闘）は `js/scenario2.js` の `STORY`。目的地の段階の `battle` は着いたシーンのあとの戦闘、`clear` は戦わずにそのステージをクリア扱いにする（先の区画の鍵になるステージを、物語では戦わないとき）。

## 地形マップの書き方

町（ぽかぽか村・街道の宿場）以外の区画は、`js/field-zones.js` の区画に書いた `map`（文字列の配列）で地形ができています。1文字が 2m 四方の1マスで、1行目が北です。

- **野外**（森・丘・街道・谷・遺跡・魔王領・樹の根もと・世界の果て・夢）：木立や岩の崖で道を区切り、分かれ道・行き止まりの広場（宝箱）・川と橋・石段で上る高台を作っている
- **ダンジョン**（笑顔の塔・黒影洞窟・魔王城・樹の地下）：階ごとに別の区画で、階段の出入口で上り下りする。上の階は物語を進める（その階のステージの前のステージをクリアする）と通れる
- **樹の地下**（`tree_under` `tree_under_2` `tree_under_3`。様式 `roots`）：封印の扉の奥、にゃんだーの樹の体の中を下りていく。階ごとに仕掛けがひとつずつで、はじめは易しく、だんだんむずかしくなる
  - B1「しおれた根の洞」（`roots`）：灰色の感情の実は、仲間といっしょに持ち上げると光る。光る実が根元の輪の中にあるあいだだけ、しおれた根は元気になり、奈落に根の橋をかける（根の茂みは、元気になると道をふさぐ）。実は一つずつしか運べず、根のゆりかごにだけ置ける。① 短い橋（持ったまま渡れる）と長い橋（持ったまま渡ると、根元の輪を出たところでしおれて岸へもどされる。ゆりかごに置いて渡る）② 長い橋を向こう岸からも支えて二つ目の実を運び、茂み（実を持って近づくと閉じる）をさけて、別の橋で根の扉へ ③ 西の小島の実を取ってきて、二つの実で谷の橋をかわるがわる支え、奥の根の扉に二つそなえる（最後に、そなえた実が茂みを起こしてしまうので、一つ取りもどす）
  - B2「影の回廊」（`shadows`）：部屋に入ると、先頭の子の「ひとりぼっちの影」が足もとからはなれ、同じ部屋の中を鏡うつしに動く（壁や柱にぶつかると止まる。影は光がきらいで、ひだまりに入ると消えて鏡の位置にあらわれなおす）。自分が金色の輪、影が紫の輪に同時に入ると、影はもどってきて（先頭の子ごとの、影の言葉と返事）、出口の影のいばらが消える。① 左右が逆に動く影を、ひだまりをよけて輪へ ② 部屋の片側にだけある柱に影を押しつけて、自分とずらす ③ 影が前後も逆に動く（部屋のまんなかで折り返す）部屋で、柱とひだまりを使ってずらす
  - B3「樹の心臓の間」（仕掛けなし）：天井の高い丸い広間の中央に、天井から下がる太い根に吊られた樹の心臓。根の血管が心臓から床をはって壁をのぼり、天井をめぐって心臓の上へもどる。鼓動（弱っているあいだはゆっくり）のたびに、床の血管を光が心臓から外へ流れ、床の紋様の輪が内から順に明るくなる。天井には色のぬけた実の殻が垂れている（樹がよみがえると四つの感情の色に光る）。ここでコドクと戦う（ステージ 7-3）
- **ねこ神の夢**（`dream` `dream_2` `dream_3`。クリア後のおまけ）：猫神社の奥の夢の中。下りるほど眠りが深くなる三つの階（うとうと → すやすや → ぐっすり）に、仕掛けがひとつずつ
  - うとうとの庭（`sizes`。様式 `dreamgarden`）：お菓子の庭が三つ北へ続く。ちびクッキーを食べると、ひとまわり小さく、でかミルクを飲むと、ひとまわり大きくなる（小さい・ふつう・大きいの三つ。仲間もいっしょ）。小さい子はキャンディの柵（`I`）のすき間をくぐれ、大きい子はケーキの段（高さ 2m）にのぼれるが、木立のあいだの 1 マスの細い道にはつかえる。段からは、だれでも飛びおりられる。① クッキーで小さくなって柵の向こうへ ② ミルクを二杯飲んで大きくなりケーキの上へ、細い道の前でクッキーを食べてもどる ③ 大きくなって二段目のケーキにのぼり、クッキーを二枚食べて小さくなってから、柵に囲まれたくぼ地へ飛びおりる。入口近くの光の輪の上では、もとの大きさにもどる
  - へんてこ回廊（`loop`。様式 `dreamhall`）：『8番出口』のような、くりかえす回廊。へんなところ（異変：さかさまの肖像画・逆に回る大時計・起きているタマ・鏡うつしの回廊・壁にひらく目 など 15 種）があれば引き返し、なければ進む。ミケそっくりの偽物・喋る魚・クロのぬいぐるみの異変は、近づくと話しかけてくる（偽物のミケは「出口はこっちだよ！」と回廊の奥へ走っていき、喋る魚は先へ進めと演説する。つられて進むと「ひっかかったー！」、引き返すと「ばれたかー」。`LOOP_TALK`）。正しければ「さかなの数」が一ぴきふえ、まちがえると 0 ひきにもどる（どこがへんだったかを教える）。5 ひきになると、回廊の先に出口があらわれる。0 ひきのときに引き返すと、回廊の外へ出られる。ぬけたかどうかは `Save.data.flags.dreamLoop`
  - 夢のできごと（`dreams`）：ねこ神は一行の旅をずっと見ていたので、夢の中には旅で出会った猫たちが出てくる。各階の専用の部屋で待っていて、話しかけると場面が見られる（見た場面の猫は、もういない）。うとうとの庭：ピクニックの丘（影の四剣）・夢の演芸場（ニャハハ王とピエロのお笑い大会）・おひるねの野原（ネムネムとタマのおひるね勝負）。へんてこ回廊：ないしょの会議室（四天王の「魔王さまをよろこばせる会」）・夢の小川の間（シロの幼なじみのユキ）。ねこ神の寝所：なつかしい家（ミケの両親）
  - ねこ神の寝所（`nap`。様式 `dreamhall`）：だるまさんがころんだ。玉座で眠るねこ神が、ねごとで「ね・こ・が・こ・ろ・ん・だ」と言い終わると、ねがえりをうってこちらを向く。向いているあいだに動く（走る・跳ぶ・こうげき）と見つかって、ふとんの線（なければ広間の入口）へもどされる。ざぶとんの山・タマの山（100匹のタマ）・大きな箱のすぐうしろなら、動いても見つからない。ねごとの速さは毎回ちがい、「だ」の前にためたり、とちゅうで「むにゃむにゃ……」と寝なおしたりする。玉座の前（ステージ 9-3）まで行けば、ねこ神が目をさます
- **ミャオ街道**（`road1` `road1_hill`）：村の北の街道。ひょうたん池のある、ゆるやかに起伏する野原（`road1`）と、その北の風車の丘（`road1_hill`。`parent: 'road1'`）。どちらも 160m 四方ほどの広い区画。丘は高さ 10m・半径 70m のなだらかな丘（いちばん急なところで 15°）で、道は南の斜面を折り返しながら上り、平らな頂上（風車と畑。シロの特訓 `c2_03e`・ステージ 2-3）をこえて、北へ下ると街道の宿場。丘は `dents` の depth を負にして作る（`top` が平らな頂上の半径。木立 `#` にはかからないように置く）。どちらも広いので、戦闘は区画をまるごと組み立てず、戦場のまわりだけの軽い背景（`battleSet`。区画の高さにそった草地・木・風車や池などの目印）
- **ごろごろ切り通し**（`road2` `road2_gate`）：宿場の北の長い岩山。暴走族のような「ごろごろ団」の走り場で、二つの区画に分かれる（北の区画は `parent: 'road2'`）
  - 入口からたまり場まで（`road2`）：南から入口（岩が一つ横切る。東に石段で上る見晴らし）→ ごろごろ坂（幅3の一本道を、坂いっぱいの大岩が行ったり来たり。脇の退避所でやりすごす）→ ごろごろ団のたまり場（80m × 56m の広い谷。岩の通り道が六本、谷の壁から壁まで横切り、通り道のあいだの岩の出っぱりで、まっすぐには渡れない。まん中の帯は団の野営。東は岩棚の行き止まり）→ 谷の北西の石段を上り、踊り場から東へ折れて出口へ。総長が改心すると（`c2_05`）、ごろごろ岩はもう走っていない（`rollersUntil`）
  - 外門（`road2_gate`）：高い崖にかこまれた、こわれた外門の手前の広場で、総長のばくそうイノシシと戦う（ステージ 2-4）。外門の先の道は崖くずれでふさがっていて、西へ折れて崖の石段を上った見晴らし台（`c2_05b`。はじめてニャハハ王国のお城が見える）を通り、東の石段を下りて関所へ
- **ニャハハ王国関所**（`sekisho`。様式 `fort`。切り通しを抜けるまで入れない。敵は出ない）：門がひとりでは開け閉めできないつくりの石の砦。腰を痛めた関所番のゴン爺にかわって、内門の踏み板・蔵の門のかんぬき（クロ）・番犬の庭（タマ）・三つののろし台（シロ）の仕事を、先頭の子を入れかえて仲間のわざで片付けていく
- **まどろみの林**：入口・ねむり花の谷・大樹のうろの三つの野外の区画（奥の二つは `parent: 'woods'`）。眠ったままのタマが、綿毛で飛ばされ、ねむり花の中で眠り、リスにどんぐりとまちがえられる——と、ハプニングを追いかけて奥へ進む
- **城下町**（ニャハハ王国）：`#` は建物の敷地。区画の組み立てで `K.townBlocks()` が敷地を長方形に分け、一棟ずつ家（木組みの壁・窓・扉・猫耳の屋根）を建てる。高台・広場・運河は床の高さと `~` `=` で作る。ニャハハ城は白い城壁に囲まれた中庭と、城の中（玉座の間・宝物庫・図書室・大広間・食堂・厨房。様式 `nyapalace`）

| 文字 | 意味 |
| --- | --- |
| `#` | 壁（野外の区画では木立・岩の崖） |
| `W` | 窓 |
| （空白） | 奈落（吹き抜け・世界の果ての空） |
| `0`〜`9` | 床（数字が床の高さ m） |
| `,` | 土の道（床。高さはとなりの床と同じ） |
| `~` | 川・池・地底湖（通れない） |
| `=` | 橋（床。下に川が流れ、両側に欄干） |
| `^` `v` `<` `>` | 階段（矢印の向きへ上る） |
| `%` | 根の橋（樹の地下。しおれているあいだは奈落、元気なあいだは岸と同じ高さの床） |
| `I` | キャンディの柵（ねこ神の夢。床。小さくなった子だけ、すき間をくぐれる） |
| `E` | 昇降機 |
| `D` | 扉（近づくと開く） |
| `a`〜`z` | 区画の出入口（`exits` の `key`。階段の `v` は使えない） |

区画の設定：

- `arch`：見た目の様式（`js/field-terrain.js` の `ARCH_STYLES`）。野外は `woods`（木立）・`crag`（岩の崖）・`abyss`（奈落に浮かぶ道）・`sweets`（お菓子の木立）・`dreamgarden`（お菓子の木立と、スポンジとクリームの層のケーキの段。柵は立てない）・`kingdom`（城下町の敷地と石畳）・`nyacastle`（城の中庭）、屋内は `tower` 笑顔の塔・`cave` 洞窟・`castle` 魔王城・`ruin` 古代遺跡の中・`roots` 樹の地下・`dreamhall` 夢の宮殿（うす紫の壁と夜空の色の天井）
- `world: true`：座標をワールド（m、区画の中央が原点）で書く。書かない区画は座標がマス（列, 行）。`anchor`・`spawn`・`npcs[].at`・`chestAt`、物語の目的地（`STORY` の `at`）、会話の舞台と戦闘の場所（`BATTLE_SETS`）も同じ座標で書く
- `exits`：`{ key, to }`。階段の出入口は `stair: 'up'`／`'down'`。野外の門（木の柱と葉）を、建物の扉の奥などで光のまくと札だけにするときは `plain: true`
- `floor`：ミニマップに出す階の名前（`1F`・`B2`・`最上階` など）。`parent`：上の階の区画に書くと、ワールドマップでは入口の区画にまとめて出る
- `chestAt`：宝箱の置き場所（行き止まりなど）。書かない分は空いている床に置く
- `seals`：影の壁と光の水晶の仕掛け（`{ id, wall: [x0, z0, x1, z1], lamps: [[x, z], ...], after, openAfter }`）。水晶をすべて灯すと壁が消える。`after` のシーンを見るまでは灯せず、`openAfter` のシーンを見たあとは、はじめから消えている。区画の組み立てで `K.seals()` を呼ぶ。`look: 'memory'` にすると「記憶のかけら」（石の祭壇に思い出の品と金色の玉。`items` で品、`memories` でふれたときにクロが語る台詞）。`look: 'laugh'` にすると「笑い袋」と「むすっと幕」（押すと袋が笑い出し、`laughs` で笑い声、`gags` で仲間の掛け合い `[[話し手, 台詞], ...]`。袋をすべて笑わせると、幕が笑った顔になって巻き上がる。`lamps: []` にして、玉のりのリング（`balls`）で開けることもできる）
  - 光の鏡（`beam: { from, dir, to, init: [色ごとの最初の向き], mirrors: [[x, z, 色], ...], rocks }`）：水晶をすべて灯すと、大水晶（`from`）が `dir` の向きへ光の筋を放つ。光の鏡（F で「/」⇔「＼」）で直角に曲げ、受けの水晶（`to`）に届くと壁が消える。同じ色（赤・青・黄・緑・紫）の鏡は、いっしょに回る。鏡・from・to はマスの中心に置く。地図の検査で、解けること・最初の向きのままでは解けていないことを確かめる
  - 灯りの時間（`hold`：秒）：一つ灯すと、その光は `hold` 秒で消える（戦闘や会話のあいだは止まる）。消える前に、すべてを灯す
  - 順番（`order`：灯す順の水晶の番号）：ちがう順にふれると、灯した光がすべて消えて `wrong` の掛け合いのあと `back` へ押しもどされる。`labels` を書くと、調べるときに品の名前が出る（どれがだれのものか、手がかりから考える）
  - わざの仕掛け：`who` を書くと、その子が先頭のときだけ動かせる（ほかの子だと、その子のひとこと `tries` と手がかり `hint`）。`look: 'beacon'` はのろし台と鉄格子の大門（`fails` でシロの魔法の失敗、`lit` で火がついたときの台詞）、`look: 'bar'` は蔵の門（かんぬきをかけた両開きの扉。`lamps[0]` がかんぬきの前）。`verb` は調べるときの文言、`done` は開いたときの掛け合い
- `voidRail: false`：奈落のふちに柵を立てない（樹の地下）
- `sizes`：ちびクッキーとでかミルク（ねこ神の夢・うとうとの庭。`{ climb, drop, stands: [{ kind: 'cookie' | 'milk', at: [x, z] }] }`）。`climb` は大きい子がのぼれる段差、`drop` はだれでも飛びおりられる段差（m）。大きさごとの見た目の大きさと体の半径は `SIZE_K`・`SIZE_R`（`js/field-zones.js`。大きい子の半径は 1 マスの半分より大きく、細い道につかえる）。台の前で F を押すと、クッキーは一段小さく、ミルクは一段大きくなる（その場が大きさに合わないと変えられない）。探索を離れたときの大きさは `Save.data.fieldResume.size`。地図の検査で、0.5m ずつの格子の点と大きさの組をたどって、台を使う回数の少ない順に出口（`d`）まで行けること（手順は `-v` で表示）、歩くだけでは行けないこと、たどりつける状態から光の輪（`anchor`）へもどれないもの（閉じこめ）がないこと（ほかの区画から来たときも）を確かめる。区画の組み立てで `K.sizeStands()`（台と柵）・`K.cakeTops()`（ケーキの上のふちのクリームといちご）を呼ぶ
- `loop`：へんてこ回廊（ねこ神の夢。`{ id, hall: [x0, z0, x1, z1], south, north, start, goal, mouthS, mouthN, pillars, lamps, portraits, clock, tama, statue, board, counter, plush, talker, fake, eye }`）。`hall` は回廊の範囲（壁の位置）、`south`・`north` は引き返した・進んだとみなす線（z）、`start` は次の回廊の始まり（北を向いて立つ）、`goal` は出口までのさかなの数。ほかは飾りの位置。異変の種類は `LOOP_ANOMALIES`。回廊の飾りはひとつのグループにまとめ、鏡うつしの異変はグループごと左右反転する。区画の組み立てで `K.loopHall()` を呼ぶ
- `dreams`：夢のできごと（ねこ神の夢。`[{ id, scene, name, who: [[人物, x, z, ポーズ], ...] }]`）。`who` の猫たちが、場面の舞台のほうを向いて待っている。話しかけると `scene` の場面へ（終わると、その場所から探索にもどる）。見たかどうかは `Save.data.flags[id]`。部屋の名前は `areas`（`[{ at: [x0, z0, x1, z1], name }]`。今いる場所の名前に出る）
- `nap`：ねこ神の寝所（ねこ神の夢。`{ god, hall, start, back, checks: [[z, [x, z]], ...], covers: [[種類, x, z, 半径], ...], until }`）。`start` の線より北へ入ると、ねごとが始まる。`back` は見つかったときにもどされる場所、`checks` はふとんの線（こえると、そこからやりなおせる）、`covers` はかくれられるもの（`pillow` ざぶとんの山・`tamas` タマの山・`gift` 大きな箱。そばにいて、ねこ神から見てかげになっていれば見つからない）。`until` を満たすと（物語のあと）、ねこ神はもう遊ばずに眠っている。区画の組み立てで `K.godNap()` を呼ぶ
- `roots`：光る実と、しおれた根（樹の地下 B1。`{ r, cradles: [[x, z], ...], fruits: [{ kind, at }], bridges: [{ id, cells, nodes }], thickets: [{ id, cells, node }], knots: [{ id, cells, cradles, openToast? }] }`）。`r` は根元の輪の半径。`cradles` は根のゆりかご（実を置ける場所）、`fruits` は感情の実（`kind`：`warai` `yujo` `omoide` `yasashi`。`at` は最初のゆりかごの番号。はじめは灰色で、一度持ち上げると光る）。`bridges` は根の橋（`cells` は地図の `%` のマスの範囲 `[x0, z0, x1, z1]`、`nodes` は根元。どれかの根元の輪に光る実があれば渡れる）、`thickets` は根の茂み（根元の輪に光る実があると道をふさぐ）、`knots` は根の扉（`cradles` のゆりかごすべてに光る実がそろうと、ほどけて開いたまま）。持っている実はプレイヤーの位置にある。足もとの橋がしおれると岸へもどされ、元気になった茂みの上にいると押しもどされる。実の置き場所は `Save.data.flags[区画 + '_fruit']`、光った実は `flags[区画 + '_lit']`、開いた扉は `flags[扉の id]`。地図の検査で、実を持つ・置く回数の少ない順にたどって、根の扉をすべて開けて下の階への階段（`d`）まで行けること（手順は `-v` で表示）、最初から解けていないこと、ゆりかごと根元の距離が輪の半径に近すぎないことを確かめる。区画の組み立てで `K.roots()` を呼ぶ
- `shadows`：影の部屋（樹の地下 B2。`[{ id, area, mirror, at, enter, goal, sgoal, lights, gate, teach? }]`）。`area` は部屋のマスの中心の範囲（プレイヤーも影もこの部屋の中を動く。影は部屋の外の通路へは出ない）。`mirror: 'x'` は x = `at[0]` の線で左右に、`'xz'` は `at` の点で折り返す（前後も逆）。`enter` は部屋の入口（影があらわれる鏡の位置の目安。鏡の線の上なら、影は足もとからはなれていく）。`goal` はプレイヤーの輪、`sgoal` は影の輪（半径 1）。`lights` はひだまり（`[x, z, 半径]`。プレイヤーは通れるが、影が入ると、鏡の位置にあらわれなおす）。`gate` は出口の影のいばら。部屋の壁は鏡の線（点）に対してそろえ、柱やひだまりを片側にだけ置いて、影をずらす手がかりにする。解いたかどうかは `Save.data.flags[id]`。地図の検査で、0.5m ずつの格子で自分と影の位置をたどり、解けること（答えの歩き方は `-v` で表示）と、影が鏡の位置のまま歩くだけでは解けないこと（`teach: true` の練習の部屋は除く）を確かめる。区画の組み立てで `K.shadowRooms()` を呼ぶ
- `plates`：関所の内門（`[{ id, name, at: [[x, z], [x, z]], wall, after, openAfter, done }]`）。肉球の踏み板をすべて同時に踏むと、石の門が左右に開く。踏み板の上で F を押すと、仲間に「ここで待ってて」とたのめる（その子は踏み板の上で待つ。もう一度 F でよびもどす）。`done` の `lead`／`helper` は、先頭の子と待っていた子の台詞（子ごとに書ける）。区画の組み立てで `K.plates()` を呼ぶ
- `guards`：見張りの番犬（`[{ id, route: [[x, z], ...], r, fov, wait, speed, back, after }]`）。道を行ったり来たりして見回り、前の扇（半径 `r`、半分の角 `fov`。壁の向こうは見えない）に入ると見つかって `back` へ追い返される。タマが先頭なら、うしろから近づいてこもりうたで眠らせられる（眠った番犬は `Save.data.flags` に残る）
- `rollers`：ごろごろ岩（`[{ a: [x, z], b: [x, z], speed, ph, r, back }]`）。a と b のあいだを行ったり来たり爆走する。ぶつかると `back` へはねとばされる。`rollersUntil`：その条件を満たすと、もう走っていない
- `rubble`：攻撃で砕ける落石の岩山（`{ id, at: [x, z], r }`）。区画の組み立てで `K.rubbles()` を呼ぶ。`look: 'jackbox'` にすると巨大びっくり箱（`act` の札つき。はじめて調べると説明、そのあとは F でねじを巻き、攻撃でふたをたたく。ちょうど `turns` 回巻いてあれば、ばねの先のピエロの顔が飛び出して消える。足りなければ何も起きず、巻きすぎると `back` へ飛ばされる。どちらも、ねじは元にもどる。`hint` で調べたときのひとこと）。灯した水晶・消えた壁・砕いた岩は `Save.data.flags` に残る
- `fluff`：綿毛（大きなたんぽぽ。`[{ at: [x, z], to: [x, z], h }]`）。F でつかまると、ふわりと浮いて、風にゆられながら `to` へ降りる（`h` は浮く高さ）。つかんだ綿毛は抜けて、しばらくすると生えなおす。川や谷の向こうへの行き来に使う。地図の検査もトランポリンと同じく、綿毛でつながる先を行ける場所として数える。区画の組み立てで `K.fluffs()` を呼ぶ
- `nemuri`：ねむり花（`[{ at: [x, z], r, ph, back: [x, z] }]`）。閉じる → ふくらむ（花がふるえ、足もとの輪が点滅）→ まわり `r` m に眠りの粉をはく、をくり返す（`ph` は花ごとのずれ）。粉をはいているあいだに入ると一行は眠ってしまい、`back` で目をさます。粉を吸った敵も、しばらく眠る。`nemuriAfter` のシーンを見るまでは、つぼみのまま眠っている。区画の組み立てで `K.nemuri()` を呼ぶ
- `naps`：眠っている子（`[{ key, name, at, y, face, scene, talk }]`）。物語でその `scene` の目的地へ向かっているあいだだけ、その場所で眠っている（`y` は高さ。たんぽぽの綿毛の上など）
- `sleepwalk`：ねぼけ歩きの子（`{ key, name, scene, route: [[x, z], ...], near, lines, end, talk }`）。物語でその `scene` へ向かっているあいだ、`route` の最初の点で待っていて、近づく（`near` m）と次の点へふらふら歩いていく（`lines` はそのときのねごと）。最後の点で丸くなって眠る
- `foes`：その区画に出る敵（強さは `stage` のまま。森の奥だけリスやきのこ、など）
- `cushions`：ブーブークッション（`[[x, z], ...]`）。踏むと鳴って、仲間がひとこと（`CUSHION_LINES`）。区画の組み立てで `K.cushions()` を呼ぶ
- `bounce`：トランポリン（`[[x, z], ...]`。マスの中心に置く）。となりのマスから踏みこむと、その向きに `bounceLen` マス先（3）へ弧をえがいて跳ぶ。着地するマスもトランポリンなら、同じ向きにもう一度跳ぶ。床のないところへ跳ぶと奈落へ落ちて、安全ネットで `bounceBack` へもどる。小さな島では踏みこめる向きがかぎられるので、道順を考える仕掛けになる。地図の検査（`tools/check-maps.js`）も、トランポリンでつながる先を行ける場所として数える。トランポリンのまわり 2 マスには敵を置かない。区画の組み立てで `K.bouncers()` を呼ぶ
- `balls`：玉のりのリング（`{ id, seal, ring: [x0, z0, x1, z1], blocks: [[x, z], ...], targets, balls, reset: [x, z], after, idle, done }`。座標はマスの中心、`ring` は大玉が動けるマスの範囲）。大玉のとなりで F を押すと、向こう側へ、リングの縁・台（`blocks`。となり合う二つは玉のり台、一つは大太鼓）・ほかの大玉にぶつかるまで転がる。スポットライトの輪（`targets`）に入ると止まる。すべての輪に大玉がそろうと、`seal` の幕が開いて `done` の掛け合い。リングのベル（`reset`）で、大玉を元の場所へもどせる。大玉の位置は `Save.data.flags[id]` に残る。地図の検査で、解けること（最短の押す回数は `-v` で表示）と、最初の置き方のままではそろっていないことを確かめる。区画の組み立てで `K.ballRing()` を呼ぶ
- `stroke`：つながりの石畳（`[{ id, name, area: [x0, z0, x1, z1], holes: [[x, z], ...], start, goal, gate: [x0, z0, x1, z1], openToast, done }]`。座標はマスの中心）。踏むと光る石の板。始まりの石（足あと）から、すべての石を一度ずつ踏み、最後に終わりの石（星）を踏むと、`gate` の結界が消えて `done` の掛け合い。光った石をまた踏む・石畳から出る・石をとばす・終わりの石を先に踏むと、光は消えてやりなおし。ひとつ前の石へもどると、一歩取り消せる。`holes` は崩れた柱。解いたかどうかは `Save.data.flags[id]`。地図の検査で、答え（すべての石を通る道）があることを確かめる（道の数は `-v` で表示）。区画の組み立てで `K.strokeBoards()` を呼ぶ
- `timeShift`：時の水晶（`{ id, crystals: [[x, z, 向き], ...], after, ghosts: [[x, z, 向き, 台詞], ...] }`。水晶の向きは `'W'` 白：今と昔のどちらへも、`'P'` 金：昔へだけ、`'N'` 青：今へだけ。使えない向きの水晶は暗く沈む。どう切りかえても入口（`anchor` の今の姿）へ戻れなくなったら、入口へもどされて今の姿にもどる）。`ghosts` は昔のあいだだけ見える昔の猫たちで、台詞があれば F で話しかけられる（地図の検査は、昔の姿で閉じこめられずに会えるかも調べる）。地図の `R` のマスは、今は瓦礫で通れず昔は通れる。`A` のマスは、昔は石の壁や門で通れず今は崩れて通れる。水晶にふれると、遺跡が「今」と「昔」で切りかわる（昔のあいだは画面が琥珀色になり、`ghosts` の昔の猫たちの面影が見える）。どちらかは `Save.data.flags[id]`（`true` ＝ 昔）。地図の検査で、入口から今の姿で歩きはじめて、物語の目的地・宝箱・出入口へ行けることを確かめる（目的地までの切りかえの回数は `-v` で表示）。区画の組み立てで `K.timeShift()` を呼ぶ
- 木立の木は区画の組み立て（`ZONE_BUILD`）で `K.flora({ trees, leaf, ... })`、崖の上の木や岩は `K.cragTop()` で植える（同じ形の部品は InstancedMesh でまとめて描く）

地図を書き換えたら、物語の目的地・会話の配役・戦闘の場所・住人・宝箱が歩いて行ける広い床の上にあるかを検査します：

```bash
node tools/check-maps.js
```

`node tools/check-maps.js 区画名 -v` で、地図に地点を重ねて表示します。

Three.js を更新する場合：

```bash
npm install && npm run build:vendor
```
