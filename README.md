# 銀河鉄路 ノクターン

「崩壊：スターレイル」のバトルシステムを参考にした、ブラウザで遊べるターン制コマンドRPG（ファンメイド）。
キャラクター・世界観・グラフィックはすべてオリジナルです。

## 起動

ビルド不要。`index.html` をブラウザで開くだけで遊べます（WebGL 対応ブラウザ推奨。WebGL が使えない環境では従来の2D表示で動作）。ローカルサーバーを使う場合：

```bash
node .claude/serve.js
```

→ http://localhost:8911

## デバッグ：章・段階へジャンプ

URL に `?debug` を付けて開く（例：`http://localhost:8911/?debug`。`index.html` を直接開く場合も末尾に `?debug`）と、開拓任務の画面に「デバッグ：章へジャンプ」が出ます。一度付けると以後も有効のままで、`?debug=0` で無効に戻ります。

- 各章の段階（会話・戦闘・探索任務）の一覧から選ぶと、その段階の直前まで進めた状態になる。「全ての章をクリアした状態」も選べる
- 前の章のステージはクリア済み、その章は目的地より前の戦闘までクリア済みになり、区画もそこまで開放される。飛ばした会話で加わる仲間（カザネなど）も加入する
- 「編成のレベルを推奨レベルまで上げる」を選ぶと、編成のキャラクターをその段階の戦闘の推奨レベルまで上げる（下げはしない）
- 探索任務へ飛んだときは、その区画の時空アンカーから歩き出す
- 最初のジャンプの前にセーブデータを退避し、「ジャンプ前のセーブに戻す」で元に戻せる

## 再現しているシステム

- **行動値（AV）による行動順**：速度が高いほど早く行動。行動順の短縮・遅延あり
- **スキルポイント（SP）**：味方全体で共有（最大5）。通常攻撃で+1、スキルで-1
- **必殺技**：EP満タンでいつでも割り込み発動。カットイン演出あり
- **弱点撃破**：弱点属性で攻撃すると靭性が減り、0になると撃破。属性ごとの撃破効果
  （物理＝裂創／炎＝燃焼／氷＝凍結／雷＝感電／風＝風化／量子＝もつれ／虚数＝禁錮）
- **運命**：壊滅・巡狩・知恵・調和・虚無・存護・豊穣（狙われやすさにも影響）
- **秘技**：戦闘開始前に秘技ポイントを消費して発動
- **ボス**：フェーズ移行（弱点が変わる）、溜め攻撃（撃破で中断）、増援召喚
- **ワープ**：5★基礎0.6%・74連目から確率上昇・90連天井、4★は10連保証、限定ガチャの50/50とすり抜け後の確定
- **星魂**：同じキャラを重ねると強化
- **模擬宇宙**：祝福を集めながら進むローグライクモード
- **会話シーンの演出（第一章・第二章）**：会話は物語の場所（第一章：カプセルホール、医務室、保管棚ギャラリー、中央管制室、炉の底、星核の壇、列車のホーム／第二章：雪原の停車場、凍てついた街路、鉱区深層の古い鉱脈、城塞の門の東、玉座の間）で演じられる。キャラクターは向き合って立ち、話し手の方を見て、表情（笑顔・驚き・困り顔・怒り・真剣など）と身振り（指さす・うなずく・手を差し出す・構える・跳ねる など）で演技する。まばたきと口パクあり。カメラは全景・寄り・肩越しを切り替え、炉の停止、隔壁が開く、星核が鎮まり封印されるといった出来事も目の前で起きる。通信はホログラムで映る。行ごとの演出は `js/story.js` の台本の行末に `{ f: 表情, g: 身振り, ... }` で書き、舞台（区画・立ち位置・カメラ）は `js/stage.js` の `SCENE_STAGES`
- **開拓任務（ストーリー）**：全4章・24シーンのオリジナルストーリー。会話シーン（3D空間で話し手にカメラが寄る、選択肢あり）→ フィールドの目的地へ移動 → 任務ステージの戦闘、の流れで進む。NPC（車掌ポルカ、研究員イリス、レジスタンスのロア、将軍ソウゲン）が登場し、章クリアで星玉を獲得
- **探索（フィールド）の地形（第一章・第二章）**：第一章ヘリオス宇宙ステーションの区画は、部屋・通路・上下の階でできた屋内マップ。天井・壁パネル・宇宙が見える展望窓・自動扉・ガラスの手すり・階段があり、吹き抜けの上の回廊、炉の底とキャットウォーク、深淵に架かる橋のように階が分かれている。階の間は階段か昇降機（F で上下、別の階から呼ぶこともできる）で移動し、区画の間は隔壁扉か、行き先の区画を選ぶステーション・エレベーターでつながる。ミニマップはプレイヤー中心の見取り図で、今いる階（1F／2F）を表示。第二章ベロワの12区画も同じ仕組みで、区画ごとに建築様式が変わる：列車が停まる雪原の崖と氷の裂け目（岩肌に雪が積もり空が見える）、石と漆喰の建物が並ぶ行政区と街路（窓に灯り、鉄の手すり、凍った運河の橋）、坑木と吊りランタンの地下鉱区（上層坑道・坑夫の集落・大縦穴の深層・北坑道。区画の間は鉄格子の「鉱区昇降機」）、狭間のある城壁の門、大理石と氷の宮殿（大広間・肖像の回廊・空の見える凍てついた庭園・玉座の間）
- **探索（フィールド）**：章ごとに3〜12の区画（計27区画）がゲートでつながったフィールドを歩き回る。区画はストーリーの舞台に対応し、地形・小物・敵・住人がその場所に合わせて作られている（例：冷凍睡眠カプセルが並ぶ収容区画、コンテナの迷路の保管庫、炉心が脈打つ動力炉、トロッコの走る地下鉱区、雲海に面した渡し場、天球儀が回る星図室）。任務を進めると先の区画が開放され、区画マップから訪れた区画へワープできる。敵に先に攻撃を当てると「先制攻撃」、接触されると「奇襲」。宝箱、秘技ポイントを回復する結晶、住人との会話、調べられる記録（端末・石碑）あり

## 3Dグラフィック

Three.js（`vendor/three-bundle.js` に同梱済み）によるリアルタイム3D描画。主人公アステルは Blender で作ったモデル、それ以外はコードで生成しています。

- **Blender製モデル**：アステルとミゾレは Blender で作ったリグ付きスキンメッシュ（`assets/blender/*.blend`）。断面ロフト＋ボクセルリメッシュの体、頬からあごへ絞ったアニメ顔、三日月断面の毛束を重ねた髪、縁取り付きの衣装、指付きの手、靴、武器（バット・氷の盾）までモデリングし、アンビエントオクルージョンを頂点カラーに焼き込み。ゲーム側では既存のポーズをボーン回転に変換して動かし（戦闘・探索・会話のアニメーションは共通）、影色付きのセルシェーディング・HSR風に描いた顔テクスチャ・アウトラインを付ける
- **キャラクター**：トゥーンシェーディング＋アウトライン＋リムライト。顔（アニメ調の目）はCanvasで描いたテクスチャ、髪型・衣装・武器はキャラごとに組み立て
- **戦闘演出**：本家風の肩越しカメラ（行動中のキャラを手前左に置き、他の味方は隠す。手持ち風の揺れ付き）、ダッシュ→斬撃の近接攻撃、弾・隕石による遠距離攻撃、必殺技のクローズアップ演出、弱点撃破時のスローモーションと破片、シールドの泡、凍結の氷塊、敵の消滅エフェクト
- **専用必殺技演出（アステル「星屑の終曲」）**：発動で画面が沈む → 星海の円盤を背にしたスプラッシュと技名 → 顔のアップ（光の帯が渦巻く）→ バットを水平に構えて帯電 → あおりで光のバットを構える → 肩越し視点で対象選択（バットは光ったまま）→ 並走カメラで踏み込み、跳躍して叩きつけ（ヒットストップ・色収差・集中線・光柱）。
- **専用必殺技演出（ミゾレ「永久凍土」）**：同じ流れで、雪の結晶の紋を背にした顔のアップ → 突き出した盾に結晶の紋が咲く → あおりで足元から氷柱が輪になって噴き出す → 肩越し視点で決定（全体攻撃も確認を挟む）→ 盾を床に叩きつけ、冷気が氷柱の列となって敵へ走り、敵全員の足元から氷山が噴き出して砕ける。専用演出は `js/gfx/views.js` の `ULT_CINE` に登録（発動・スプラッシュは共通、クローズアップと攻撃はキャラごと）
- **ステージ**：宇宙ステーション／雪原の城塞（オーロラ・降雪）／仙舟（楼閣・灯籠・月）／星核の深淵（ブラックホール・浮遊結晶）
- **第一章・第二章の戦闘の背景**：戦う場所の区画をそのまま背景にする（第一章：カプセルホール、倉庫のコンテナの通路、中央管制室のホロテーブル前、炉の底、深淵に架かる橋と星核、ドックのコンコース／第二章：谷の雪原、凍てついた街路、大縦穴の足場と古い鉱脈、城塞の前庭と門、玉座の間、坑道・大広間・肖像の回廊・凍てついた庭園）。任務の戦闘も探索中の戦闘も同じ。場所は `js/stage.js` の `BATTLE_SETS` / `ZONE_ARENAS`
- **星核の番人の第二形態**：形態変化で番人に寄って光を吸い込み、閃光・衝撃波・光柱とともに解放する演出。第二形態のあいだは、足もとの魔法陣、背後の紋、周りを巡る赤い結晶、赤黒い渦と稲妻、鼓動のような衝撃波と舞う火の粉、背景の星核の暴走で威圧感を出す
- **氷刃の女帝の第二形態**：同じ流れを氷の演出で。画面が青く沈み、雪と光を吸い込んでから、周りに氷の棘を突き出して解放する。第二形態のあいだは、霜の魔法陣、周りを巡る氷の結晶、戦場を吹き抜ける吹雪、味方の足もとから突き出して砕ける氷の棘、青く沈む空気で威圧感を出す（演出の型は `js/gfx/views.js` の `P2_STYLES`）
- **ポストエフェクト**：ブルーム、ACESトーンマッピング、ビネット、SMAA
- **その他**：ハブ・キャラ画面は3Dモデルをドラッグで回転、ワープはハイパースペース演出からキャラ登場、HUDの肖像も3Dモデルからレンダリング

Blender モデルを作り直す／書き出す場合（Blender 4.2 以降）：

```bash
npm run build:models
```

`tools/blender/build_<名前>.py`（共通部品は `charlib.py`）がモデルを一から組み立てて `assets/blender/<名前>.blend` を保存し、`tools/blender/export_glb.py` が `assets/models/<名前>.glb` と、`file://` でも読めるよう base64 で埋め込んだ `assets/models/<名前>.js` を書き出します。1人だけ作り直す場合は `sh tools/blender/build.sh mizore`。Blender で `.blend` を直接編集した場合は書き出しだけ実行：

```bash
/Applications/Blender.app/Contents/MacOS/Blender -b assets/blender/mizore.blend -P tools/blender/export_glb.py
```

キャラを追加したら `index.html` に `assets/models/<名前>.js` の読み込みを足してください。ボーン名（`hips` `upper_arm.L` など）とマテリアル名（`skin` `face` `accent` `glow` など）はゲーム側が参照するので変えないでください。腕は20°開いた A ポーズが基準です（`GLB_ARM_REST`）。

Three.js を更新する場合：

```bash
npm install && npm run build:vendor
```

## 屋内マップの書き方

`js/field-zones.js` の区画に `map`（文字列の配列）を書くと、部屋と階のある屋内マップになります。1文字が 2m 四方の1マスで、1行目が北です。

| 文字 | 意味 |
| --- | --- |
| `#` | 壁 |
| `W` | 窓（外の宇宙が見えるガラス壁。マップの外周に置く） |
| （空白） | 奈落（吹き抜け。橋や張り出しの下に深淵が見える） |
| `0`〜`9` | 床（数字が床の高さ m） |
| `^` `v` `<` `>` | 階段（矢印の向きへ上る。両端の床の高さを結ぶ） |
| `E` | 昇降機（となり合う床の高さのあいだを上下する） |
| `D` | 自動扉（近づくと開く） |
| `a`〜`z` | 区画の出入口（`exits` の `key`。`to` なら隔壁扉、`lift: [...]` ならステーション・エレベーターの籠） |

扉で区切られた範囲ごとに天井が付き、高さは部屋のいちばん高い床 + `wallH`（既定 6m、様式ごとの既定あり）。

区画の `arch` で建築様式を選べます（`js/field-terrain.js` の `ARCH_STYLES`）。

| `arch` | 様式 | 天井 | 扉・出入口・昇降機 |
| --- | --- | --- | --- |
| `station`（既定） | 宇宙ステーション：パネルの壁、光る段鼻、ガラスの手すり | あり | 自動扉・隔壁扉・ステーション・エレベーター |
| `town` | 雪の町：灯る窓の並ぶ建物、雪の積もる屋根の縁、鉄の手すり | なし（空） | 観音開きの扉・石の門・鉄格子の昇降機 |
| `fort` | 城塞：窓のない切り石の城壁と狭間 | なし（空） | 同上 |
| `cliff` | 雪原の崖：凹凸のある岩肌と雪、木の柵 | なし（空） | 同上 |
| `mine` | 坑道：岩の壁と天井、坑木の柱と梁、吊りランタン | あり | 木の扉・坑口・鉄格子の昇降機 |
| `palace` | 宮殿：大理石と氷、青く光る縁取り、格天井 | あり | 大理石の扉・門・鉄格子の昇降機 |
| `court` | 宮殿の庭：大理石の壁に囲まれた庭 | なし（空） | 同上 |

空の見える様式では、壁（`#`）の塊が建物や岩山になり、高さは近くの床より `wallH` 高く、町は建物ごと・崖は岩ごとに上端が揃わないようにばらつきます。区画間の昇降機の籠の名前は出口の `name`（例：`{ key: 'l', name: '鉱区昇降機', lift: [...] }`）。区画の `anchor`・`spawn`・`npcs[].at` などの座標と、開拓任務の目的地（`js/story.js` の `at`）はマス座標（列, 行）で書きます。
